Why Does the t Distribution Have Heavier Tails?

从正态总体反复抽样，比较使用已知 σ 与使用估计值 S 的标准化结果。

X₁, …, Xₙ 独立同分布于 N(μ, σ²)
Z = (X̄ − μ)/(σ/√n) ∼ N(0, 1)
T = (X̄ − μ)/(S/√n) = Z/(S/σ) ∼ tn−1

为便于比较中心与尾部，横轴采用指定范围。 范围外的观测未显示，但仍计入统计量； 直方图密度以全部 B 次模拟归一化。

② 样本标准差 S

S 直方图 总体标准差 σ

当 S 比 σ 小时，|T| = |Z|/(S/σ) 比 |Z| 大。 随着 n 增大，S 更集中于 σ 附近，T 的分布更接近 Z。

③ 经验统计量与理论结果

变量 经验均值 理论均值 经验方差 理论方差

表中经验方差使用 B − 1 作为分母。 Z 与 S 独立；T 使用 S 构造，因此 T 与 S 一般不独立。 当 n ≥ 4 时，它们的理论 Pearson 相关系数仍为 0： 零相关不等于独立。

探索问题

  • 将 n 改为 2、5、10、30，观察 T 的尾部如何变化。
  • 增大 B，比较经验密度与理论曲线的吻合程度。
  • 固定种子，只改变 μ：哪些图和统计量保持不变？
  • 固定种子，只改变 σ：S 的分布如何变化？Z 与 T 是否改变？
  • 为什么 T 与 S 的相关系数接近 0，却不能说明它们独立？

固定 n、B 和种子时，改变 μ 或 σ 不改变标准化后的 Z 与 T； S 则随 σ 成比例变化。这体现了正态模型的位置与尺度不变性。
