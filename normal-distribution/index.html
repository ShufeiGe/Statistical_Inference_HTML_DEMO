Sampling Distribution Demo

正态总体下，探索样本均值 X̄ 与标准化样本方差 Q = (n − 1)S² / σ² 的抽样分布。

① 理论结果

X₁, …, Xₙ 独立同分布于 N(μ, σ²)。

样本均值

X̄ ∼ N(μ, σ²/n)
这里 N 的第二个参数表示方差。

标准化样本方差

Q = (n − 1)S²/σ² ∼ χ²(n − 1)
S² 使用 n − 1 作为分母。
E(Q) = n − 1；Var(Q) = 2(n − 1)。

独立性

X̄ 与 S² 独立
Corr(X̄, Q) = 0
这是正态样本的性质。有限次模拟的经验相关系数通常不会恰好为 0。
